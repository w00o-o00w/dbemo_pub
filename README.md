# Dbemo

Офлайн-програма для скріншотів: зробити знімок, позначити стрілками, рамками й номерами, приховати чутливі дані, скопіювати або зберегти.

**Працює повністю офлайн.** Програма не виходить в інтернет, нічого не відправляє і не завантажує. Знімки лишаються тільки на вашому комп'ютері.

## Завантажити

Готові інсталятори — у розділі **[Releases](../../releases/latest)**.

| Система | Файл |
|---|---|
| Windows 10 / 11 | `Dbemo_x.y.z_x64-setup.exe` |
| macOS (Apple Silicon) | `Dbemo_x.y.z_aarch64.dmg` |
| Ubuntu / Debian / Mint | `Dbemo_x.y.z_amd64.deb` |

## Перший запуск

**Windows.** Програма не підписана платним сертифікатом, тому Windows може показати «Windows захистила ваш ПК». Натисніть «Докладніше» → «Усе одно запустити». Потрібен WebView2: він уже є в Windows 11 і оновленій Windows 10.

**macOS.** Клацніть по Dbemo правою кнопкою → «Відкрити» → «Відкрити». При першому знімку дозвольте «Запис екрана»: Системні параметри → Конфіденційність і безпека → Запис екрана → увімкнути Dbemo, потім перезапустити програму.

**Ubuntu / Debian / Mint.** Встановлення: `sudo apt install ./Dbemo_*.deb`. Для знімків потрібен системний портал (`xdg-desktop-portal`), у GNOME і KDE він уже є.

## Як користуватися

1. **Screenshot**: виділіть область (Esc — скасувати).
2. Позначте потрібне: стрілка `A`, рамка `R`, приховати `B`, номер `N`, колір `1`–`9`, товщина S / M / L.
3. **Copy** `Ctrl+C` — у буфер обміну, **Save** `Ctrl+S` — PNG у `Документи/Dbemo_png_screen_Save`.

Скасувати / повторити: `Ctrl+Z` / `Ctrl+Shift+Z` (на Mac — `⌘`). Вставити картинку з буфера: `Ctrl+V`.
